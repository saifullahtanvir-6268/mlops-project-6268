## Project Description

This project implements a House Price Prediction machine learning
workflow using Python and Scikit-Learn.

## Installation

Install the required dependencies:

```bash
pip install -r requirements.txt
```

or we can run the commands as follow:

```bash
pip install pandas
pip install scikit-learn
pip install joblib
```

then below command to run the project

```bash
python src/train_6268.py
```
